## 📋 Usage Instructions

### 1. Install
```bash
npm run install-all
```

### 2. Configure
```bash
cd server
cp .env.example .env
# Edit .env with MongoDB URI
```

### 3. Seed Database
```bash
node seed.js
```

### 4. Start
```bash
cd ..
npm run dev
```

### 5. Access
- Frontend: http://localhost:3000
- Backend: http://localhost:5000
